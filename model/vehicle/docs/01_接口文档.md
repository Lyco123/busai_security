# 01 接口文档（极简版）

## 1. 本地入口

| 入口 | 作用 |
|---|---|
| `app_weight_update.py` | 训练模型，生成 Weight 产物 |
| `app_score_update.py` | 读取指定权重版本，生成 Score 结果 |

## 2. Weight 入口配置

在 `app_weight_update.py` 顶部修改：

```python
WEIGHT_RUN_DEFAULTS = {
    "start_date": "2026-04-01",
    "end_date": "2026-04-30",
    "create_date": "2026-05-01",
}

RAW_SOURCE_PATH = "data/*feature_source*.csv"
OUTPUT_DIR = "output"
```

运行：

```bash
python app_weight_update.py
```

## 3. Score 入口配置

在 `app_score_update.py` 顶部修改：

```python
SCORE_RUN_DEFAULTS = {
    "start_date": "2026-04-01",
    "end_date": "2026-04-30",
    "create_date": "2026-05-01",
}

RAW_SOURCE_PATH = "data/*feature_source*.csv"
WEIGHT_TABLE_PATH = "output/weight_xxx/02_weights/XGB正式权重表_xxx.csv"
```

运行：

```bash
python app_score_update.py
```

## 4. Score 输出

默认输出 7 张表：

| 序号 | 文件 |
|---|---|
| 01 | `01_评分汇总表` |
| 02 | `02_特征原值表` |
| 03 | `03_特征归一化值表` |
| 04 | `04_特征贡献值表` |
| 05 | `05_每日监控表` |
| 06 | `06_无法评分车辆名单` |
| 07 | `07_缺失值填充名单` |

## 5. 数据库对接替换点

只改入口或 `src/data_io.py`：

| 位置 | 本地 | 数据库替换 |
|---|---|---|
| raw 宽表读取 | `read_feature_source()` | `read_raw_db(...)` |
| Score 模型产物读取 | `load_score_bundle()` | 读取同版本模型、权重、统计表 |
| Weight 保存 | `save_weight_result()` | `save_weights_dict(...)` |
| Score 保存 | 7 个 `save_xx_*()` | 写主表、贡献表、监控表 |

不要把数据库读写写进 `features.py` 或 `modeling.py`。
