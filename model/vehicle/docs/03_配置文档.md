## 2. 输出口径

位置：`src/config.py`

```python
SCORE_OUTPUT_MODE = "formal"
```

可选：

| 值 | 含义 |
|---|---|
| `formal` | 默认，正式分 |
| `scorecard` | 评分卡分 |

## 3. 正式策略

位置：`src/config.py`

```python
BUSINESS_SCORE_THRESHOLD = 65.0
ALERT_CONFIG = {
    "energy_top_percent": 0.30,
    "fault_top_percent": 0.05,
    "business_score_threshold": BUSINESS_SCORE_THRESHOLD,
}
```

## 4. 不建议随意改

| 配置 | 原因 |
|---|---|
| `ENERGY_FEATURES` | 能耗正式特征 |
| `FAULT_FEATURES` | 故障正式特征 |
| `LABEL_CONFIG` | 标签定义 |
| `OUTLIER_RULES` | 异常规则 |
| 缺失填充配置 | 影响模型输入 |
| 归一化配置 | 影响模型输入 |
| XGB 参数 | 影响模型结果 |
| `LEVEL_1_WEIGHT_MAP` | 综合分公式 |

## 5. 数据库替换原则

- raw 数据读取：替换 `read_feature_source()`
- 权重和模型读取：替换 `load_score_bundle()`
- Weight 写库：替换 `save_weight_result()`
- Score 写库：替换 7 个 `save_xx_*()` 函数
- 不改 `features.py` 和 `modeling.py` 的计算逻辑
