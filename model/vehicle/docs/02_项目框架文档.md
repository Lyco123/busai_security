# 02 项目框架文档（极简版）

## 1. 目录结构

```text
project/
├── app_weight_update.py
├── app_score_update.py
└── src/
    ├── config.py
    ├── data_io.py
    ├── features.py
    ├── preprocessing.py
    ├── modeling.py
    └── utils.py
```

## 2. 模块职责

| 文件 | 职责 |
|---|---|
| `app_weight_update.py` | 配置训练时间、读取 raw、训练、保存 Weight |
| `app_score_update.py` | 配置评分时间、读取 raw 和权重、评分、保存结果 |
| `config.py` | 业务配置、特征清单、阈值、模型参数 |
| `data_io.py` | 所有读入和输出 |
| `features.py` | raw 宽表 → 特征和标签 |
| `preprocessing.py` | 异常、缺失填充、归一化、质量判断 |
| `modeling.py` | 训练、预测、放缩、贡献分、结果表构造 |
| `utils.py` | 日志、日期、车辆 ID 等工具 |

## 3. Weight 流程

```text
读取 raw 宽表
→ 构建训练特征和标签
→ 缺失填充、归一化
→ 训练能耗/故障 XGB
→ 保存模型 json、权重表、统计表、效果表
```

## 4. Score 流程

```text
读取 raw 宽表
→ 读取指定 Weight 版本 bundle
→ 构建评分特征
→ 缺失填充、归一化
→ XGB predict_proba
→ Top30% / Top5% 放缩
→ 输出 7 张表
```

## 5. 核心规则

| 项目 | 当前口径 |
|---|---|
| 能耗预警 | 每日 Top30% |
| 故障预警 | 每日 Top5% |
| 业务阈值 | 65 |
| 综合分权重 | 能耗 0.6，故障 0.4 |
| 模型文件 | XGBoost 原生 `.json` |
| Score 默认输出 | `formal` 正式分 |

## 6. 代码边界

- `features.py` 不读数据库、不读文件
- `modeling.py` 不读文件、不写文件
- `data_io.py` 负责所有 I/O
- 未来数据库对接只改入口或 `data_io.py`
