# RAG 与 Omni 接入验证用例

更新时间：2026-04-12

## 验证目标

1. 验证知识库检索服务可以根据制度问题召回正确制度片段。
2. 验证通用问题被分配到 `consult_omni` / `omni` 时，可以触发知识库检索，并基于检索内容回答。

## 测试前提

- 三份制度文档已完成知识库入库并完成向量索引：
  - `穗巴士集〔2023〕214号 广州巴士集团有限公司关于印发安全生产风险分级管控和隐患排查治理办法的通知（校对稿）.md`
  - `穗巴士集〔2022〕84号 广州巴士集团有限公司关于印发服务投诉管理规定的通知（校对稿）.md`
  - `穗巴士集〔2023〕41号 广州巴士集团有限公司关于印发消防安全管理规定的通知（校对稿）.md`
- Agent 环境已配置 `KB_API_BASE_URL`。
- 默认知识库 `KB_DEFAULT_ID` 指向制度知识库，例如 `regulations`。
- AI 助手问题最终应进入 `consult_omni` / `omni`，而不是结构化报告 worker。

## 建议执行方式

1. 先用知识库页面或 `/kb/retrieve` 直接检索，`top_k` 建议设为 `8`，记录命中文档、片段标题和 score。
2. 再在 AI 助手中输入对应的 omni 问法。
3. 检查前端元数据或消息标识是否显示 `consult_omni` / `omni`。
4. 对照每条用例的通过标准，判断回答是否确实来自制度条款。

## 用例 1：隐患排查治理频次与档案保存

### 验证目的

验证《安全生产风险分级管控和隐患排查治理办法》能被检索，且 omni 能回答具体制度要求。

### 直接检索 query

```text
安全生产隐患排查每月至少几次？隐患排查治理档案保存多久？
```

### Omni 问法

```text
按集团制度，我们下属单位做安全隐患排查和档案管理有什么最低要求？重点说频次、档案内容和保存期限。
```

### 期望召回来源

`穗巴士集〔2023〕214号 广州巴士集团有限公司关于印发安全生产风险分级管控和隐患排查治理办法的通知（校对稿）.md`

### 关键命中内容

- 第十六条：每月至少开展 1 次安全生产隐患排查工作。
- 第十九条：建立安全隐患排查治理信息档案。
- 第十九条第四项：安全隐患排查治理信息档案应当至少保存 3 年。
- 第二十一条：下属单位每个月统计、分析并向公司安全服务部报送月度隐患排查治理工作情况。

### 通过标准

- 检索结果 top results 中应出现 214 号文。
- omni 回复应明确“每月至少 1 次”“档案至少保存 3 年”。
- 回复最好能提到月度统计分析/报送，或安全隐患排查整改记录、重大隐患治理记录、专门台账等档案内容。
- 不应回答成消防检查或服务投诉流程。

## 用例 2：服务投诉办结期限与证据保存

### 验证目的

验证《服务投诉管理规定》检索正常，并验证 omni 能从服务投诉制度里提炼处理流程。

### 直接检索 query

```text
服务投诉原则上多少天内办结？投诉证据材料和台账保存多久？
```

### Omni 问法

```text
乘客服务投诉转到责任单位后，集团制度要求怎么处理？请说清楚办结期限、调查取证、回复投诉人和材料保存要求。
```

### 期望召回来源

`穗巴士集〔2022〕84号 广州巴士集团有限公司关于印发服务投诉管理规定的通知（校对稿）.md`

### 关键命中内容

- 第十一条：接到服务投诉后原则上为 7 个自然日内完成调查处理、答复投诉人、系统闭环登记。
- 第十二条第二项：可运用车载/站场视频监控、公交智能调度系统、羊城通刷卡记录等调查取证。
- 第十二条第三项：在规定时限内将调查处理情况答复投诉人。
- 第十二条第四项：服务投诉相关证据材料保存不少于 2 年。
- 第十二条第七项：服务投诉台账资料保存不少于 2 年。

### 通过标准

- 检索结果应召回 84 号文，而不是风险分级或消防文件。
- omni 回复应明确“原则上 7 个自然日”“证据材料/台账不少于 2 年”。
- 应提到调查取证手段至少一种：视频监控、智能调度、羊城通刷卡记录。
- 如果回答只泛泛说“及时处理投诉”，算未通过。

## 用例 3：消防演练频次、重点单位培训与新能源车辆演练

### 验证目的

验证《消防安全管理规定》能召回长文中分散条款，尤其是有明确数字的内容。

### 直接检索 query

```text
消防演练每年至少几次？消防重点单位多久演练一次？新能源车辆应急演练频次是多少？
```

### Omni 问法

```text
我们要做年度消防安全工作安排，集团制度对消防演练、消防重点单位演练、LNG和纯电动车辆应急演练有什么频次要求？
```

### 期望召回来源

`穗巴士集〔2023〕41号 广州巴士集团有限公司关于印发消防安全管理规定的通知（校对稿）.md`

### 关键命中内容

- 第五条第二项：各直属单位每年至少组织一次消防演练，演练记录存档两年以上备查。
- 第十八条第二项：消防安全重点单位每半年至少组织一次消防演练。
- 第四十二条第一项：每年至少组织一次员工消防演练，消防重点单位至少每半年一次有针对性演练。
- 第四十五条：消防安全重点单位至少每半年一次，其他单位每年至少一次；营运单位 LNG 车辆及纯电动等新能源车辆应急演练每年不少于十二次。

### 通过标准

- 检索结果应召回 41 号文。
- omni 回复应区分普通直属单位、消防安全重点单位、新能源车辆三类频次。
- 必须出现“每年至少一次”“每半年至少一次”“每年不少于十二次”。
- 如果只答普通消防演练每年一次，漏掉重点单位或新能源车辆，算部分通过。

## 用例 4：跨制度保存期限速查

### 验证目的

验证同一问题中混合“投诉”“消防”“隐患”时，检索是否能召回多份制度，omni 是否能分主题回答，而不是只命中一份。

### 直接检索 query

```text
投诉材料保存、消防演练记录保存、安全隐患排查档案保存分别多久？
```

### Omni 问法

```text
我想做一个制度台账保存期限速查：服务投诉材料、消防演练记录、安全隐患排查治理档案分别要保存多久？请按制度来源分开答。
```

### 期望召回来源

- `穗巴士集〔2022〕84号 广州巴士集团有限公司关于印发服务投诉管理规定的通知（校对稿）.md`
- `穗巴士集〔2023〕41号 广州巴士集团有限公司关于印发消防安全管理规定的通知（校对稿）.md`
- `穗巴士集〔2023〕214号 广州巴士集团有限公司关于印发安全生产风险分级管控和隐患排查治理办法的通知（校对稿）.md`

### 关键命中内容

- 服务投诉：证据材料/台账保存不少于 2 年。
- 消防演练：演练记录存档两年以上备查。
- 隐患排查治理：信息档案至少保存 3 年。

### 通过标准

- 直接检索 top 结果最好能覆盖 2-3 份文档；如果 `top_k=8`，应尽量看到三份。
- omni 回复应按“服务投诉 / 消防演练 / 隐患排查治理”分开列。
- 数字必须分别是：2 年、2 年以上、3 年。
- 如果把三个保存期限混成同一个数字，说明 RAG 内容吸收或检索区分不稳定。
