# Agent开发周报 2026-03-25

## 1. MCP 工具接入继续推进

**背景**：上周已经打通了内外网访问链路，也和 MCP 服务完成了第一轮联调，但 Agent 这边还没有方便直接验证的测试入口，工具返回结果也不够统一，部分参数定义还要靠系统侧临时兜底，离稳定使用还有一些差距。

**方案说明**：本周按“先能用、再稳定、最后去掉临时方案”的顺序推进 MCP 接入。一边补测试页面、调用链路和结果展示，一边处理空字符串参数、返回格式不统一、参数定义不兼容这些问题，最后把系统里为了联调临时加的特殊处理逐步去掉。

**功能说明**：
- 新增 MCP 测试页和后端测试接口，可以直接在系统里发起工具调用、查看返回结果，确认服务是否可用
- Agent 回复里补充了工具调用信息，方便区分“模型自己回答”还是“调用了外部工具”
- 把 MCP 返回结果做了统一处理，减少前端展示和后续判断时的兼容成本
- 修复了空字符串参数、参数定义临时覆盖、工具结果透传等接入问题，减少联调时的报错
- 在验证完成后，去掉了一部分为了联调临时写的特殊处理，让接入方式更统一

---

## 2. AB 实验切换到新阶段：车辆专家拆分实验

**背景**：之前做的 AB 实验，测试的是当规则分数达到一定阈值后，到底是“强制派发给规则链路”更好，还是“交给路由自己判断”更好。这个旧实验目前已经结束，结论是让路由自己决定整体效果更好，所以现网基线路由已经固定为 `router_decide`。在这个基础上，本周开始转向新的 AB 实验，验证通用咨询能力是否需要按专业领域继续拆分，第一步先从“车辆专家拆分”开始。

**方案说明**：本周主要做两件事。第一，把旧路由 AB 的结论正式收口到当前实现里，不再继续围绕 `force_rule` 和 `router_decide` 做对比；第二，把新的“车辆专家拆分”实验接到线上，通过 X/Y 两组对比“车辆问题继续由 omni 处理”和“车辆问题交给车辆专家处理”两种方案。

**功能说明**：
- 明确旧路由 AB 已结束，现网基线路由固定为 `router_decide`
- 更新测试迭代方案和相关文档，把当前有效实验切换为“车辆专家拆分 AB”
- 补上新的实验配置、统计清零脚本和前端统计展示，方便重新开始看板统计
- 新增并完善 `ab-x`、`ab-y` 两套路由技能，把“是否拆出车辆专家”这件事接到真实流量里观察
- 用完整的 X/Y 路由技能替换原来的车辆二次分流方案，并继续收紧 Y 组判断条件，减少误判
- 补充 Playwright 实验脚本和测试方案文档，方便复现、盲测和回归检查

## 3. 报告查询路由继续收口：从修问题到统一入口

**背景**：上周虽然已经把几类报告的主流程基本对齐，但还剩两个问题。一是实体识别和元信息识别还有漏判，二是“查报告”这类请求还比较分散，用户说得稍微模糊一点就可能走错路。

**方案说明**：本周继续按“先把明显问题修掉，再把入口统一起来”的思路推进。前半周先修车辆元信息路由、实体提取和误判问题；后半周再把报告查询入口收成一套通用逻辑，让驾驶员、车辆、线路、事故报告都走更一致的判断方式。同时，也顺手去掉了一些前置流程里过于死板的限制，减少系统在还没真正理解用户意图前就提前拦截或固定分流的情况。

**功能说明**：
- 修复车辆元信息路由问题，避免部分车辆相关问题被分到错误技能，或者在中间空转
- 修复实体提取和结构化查找的漏判问题，补齐报表场景下的名称识别和流式消息展示
- 加入针对误导性输入和注入类输入的处理，降低路由被带偏的概率
- 调整结构化查找方式，让模型先按提示词完成提取和澄清，再进入后续解析
- 把报告查询从分散规则收成统一入口，让四类报告的触发方式和澄清逻辑更一致
- 去掉了一部分“只要看起来像某类报告就先固定追问”的前置限制，改成先判断用户到底是在查信息还是要生成报告，减少误拦截
- 去掉了一些写死的前置判断和临时兜底，让更多请求回到统一路由里再做决定，前置流程只保留确实必要的短路场景
- 修复咨询场景下的输出兜底，避免已经进入咨询链路后，结果还是不完整或不自然

## 4. 调试信息和交互体验补齐：让问题更容易看出来

**背景**：之前很多 Agent 问题不是“没有做”，而是“做了但看不出来”。工具有没有调用、流式消息有没有丢、实验命中情况怎么样，都要反复翻日志看，联调成本比较高。

**方案说明**：本周先围绕研发调试把最关键的信息放到前台。重点是把工具调用、MCP 测试、AB 统计和流式渲染这些信息做成直接可见，先把问题暴露出来，再看后面要不要继续抽象。

**功能说明**：
- 前端补齐了 MCP 测试页面、研究页入口和相关接口定义，降低工具联调门槛
- 回复结构加上工具调用信息后，前端也同步支持展示，方便直接看到有没有真正调用外部工具
- 修复流式消息渲染问题，减少回答过程中片段丢失、顺序错乱或内容被覆盖的情况
- 更新 AB 统计面板和相关配置，让实验流量和命中情况可以直接看到
