**背景**：实现用户登录和权限控制，提升系统的安全性和用户管理能力。

**方案说明**：

## 2. Issue类型治理系统

**背景**：解决Issue类型管理混乱的问题，实现类型统计、合并和规范化管理。

**方案说明**：建立多对多的Issue类型系统，支持类型创建、启停用、合并等操作，实现类型数据的规范化管理。

**功能说明**：
- **类型管理**：支持创建、搜索、重命名、启停用Issue类型
- **类型合并**：支持将多个类型合并为一个目标类型（可新建），自动回写历史关联数据
- **统计分析**：显示每个类型的Eval和Issue数量统计
- **数据迁移**：从原有单值字段迁移到多对多关联表结构

**数据库设计**：
- agent_issue_types：类型主表，支持启停用和合并标记
- agent_eval_issue_types：评估记录与类型的多对多关联
- agent_issue_issue_types：问题记录与类型的多对多关联
- agent_issue_type_merges：类型合并历史记录
