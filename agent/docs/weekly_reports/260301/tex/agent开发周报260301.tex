\section{用户认证系统}

\textbf{背景}：实现用户登录和权限控制，提升系统的安全性和用户管理能力。

\textbf{方案说明}：
\begin{itemize}
\item 实现完整的用户认证体系，包括匿名用户功能、登录页面、认证上下文、会话管理和权限控制
\item 支持管理员和普通用户两种角色，按角色控制可见数据和功能权限
\item 在会话表中添加owner\_id字段，支持会话归属管理
\end{itemize}

\textbf{功能说明}：
\begin{itemize}
\item 登录页面：提供用户名密码登录，支持演示账号（user/user123）
\item 认证上下文：提供登录、登出、会话刷新等功能
\item 权限控制：基于用户角色动态显示导航菜单和管理功能
\item 会话管理：支持安全的认证会话管理和跨域cookie处理
\end{itemize}

\textbf{备注}：
\begin{itemize}
\item 生产环境权限管理由数据层提供
\end{itemize}

\section{Issue类型治理系统}

\textbf{背景}：解决Issue类型管理混乱的问题，实现类型统计、合并和规范化管理。

\textbf{方案说明}：建立多对多的Issue类型系统，支持类型创建、启停用、合并等操作，实现类型数据的规范化管理。

\textbf{功能说明}：
\begin{itemize}
\item \textbf{类型管理}：支持创建、搜索、重命名、启停用Issue类型
\item \textbf{类型合并}：支持将多个类型合并为一个目标类型（可新建），自动回写历史关联数据
\item \textbf{统计分析}：显示每个类型的Eval和Issue数量统计
\item \textbf{数据迁移}：从原有单值字段迁移到多对多关联表结构
\end{itemize}

\textbf{数据库设计}：
\begin{itemize}
\item agent\_issue\_types：类型主表，支持启停用和合并标记
\item agent\_eval\_issue\_types：评估记录与类型的多对多关联
\item agent\_issue\_issue\_types：问题记录与类型的多对多关联
\item agent\_issue\_type\_merges：类型合并历史记录
\end{itemize}
